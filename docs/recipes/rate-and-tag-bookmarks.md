# Rate and tag bookmarks

Mark what matters with stars and tags, then find it again by search, sort or group.

## One bookmark

Select it, then press `1` to `5` for its stars (`0` clears them) and `T` to type tags (Enter or a comma adds one).
The same controls are in its Details, under *Your rating* and *Tags*.

## Many at once

Select several (Space, or ⌘-click), then *Actions › Label them*: *Rate*, *Add a tag…* or *Remove a tag…*. A selected
folder counts every bookmark inside it. The whole change is one history entry, so Undo takes it back.

## Find them again

```text
#read-later          search: the tag exactly
read later           search: any bookmark whose title, address, note or tags say it
```

Then View › Sort › *Highest rated*, or Group by › *Tag* or *Rating*. Every field is described in [labels](../tools/labels.md).
